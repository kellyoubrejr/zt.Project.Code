# 速运API · 路由查询接口

> **接口服务代码**: `EXP_RECE_SEARCH_ROUTES`

---

## 1. 功能描述

客户可通过此接口查询顺丰运单路由，顺丰会在响应Json报文返回当时点要求的全部路由节点信息。

**说明**：
- 可查询3个月内运单路由，路由响应空值代表无查询权限/无路由/超3个月
- 响应报文为MOCK，不受全流程测试工具影响

### 支持三类查询方式

| 方式 | 说明 |
|------|------|
| 按顺丰运单号查询 | 限月结付款：运单号付款使用的月结卡号与partnerID存在绑定关系，系统返回路由信息；反之routes响应空值 |
| 按客户订单号查询 | 验证partnerID与订单号的归属关系，找到对应运单号后返回路由信息 |
| 按运单号+收寄人电话后4位 | 通过`checkPhoneNo`传入电话号码后4位（多个用英文逗号隔开），校验匹配后返回路由 |

## 2. 接口定义

### 2.1 公共参数

| 名称 | 值 |
|------|-----|
| 接口服务代码 | `EXP_RECE_SEARCH_ROUTES` |
| 生产环境地址 | `https://bspgw.sf-express.com/std/service` |
| 香港生产环境 | `https://sfapi-hk.sf-express.com/std/service` |
| 沙箱环境地址 | `https://sfapi-sbox.sf-express.com/std/service` |
| 批量交易 | 最多10个tracking_number |
| 接口类型 | 接入 |
| 报文类型 | JSON |

**开发规范要点**：

1. 通讯双方采用HTTP作为通讯协议
2. 提交方式为 **POST**，请求头须添加 `Content-type: application/x-www-form-urlencoded`，字符集编码统一使用 **UTF-8**
3. 参数需要通过 **http URL编码** 传送
4. 业务数据统一以字符串格式放在 `msgData` 字段中传送

---

### 2.2 公共请求参数

| 序号 | 参数列表 | 类型 | 是否必传 | 含义 |
|------|----------|------|----------|------|
| 1 | `partnerID` | String(64) | 是 | 合作伙伴编码/顾客编码 |
| 2 | `requestID` | String(40) | 是 | 请求唯一号UUID |
| 3 | `serviceCode` | String(50) | 是 | 接口服务代码（`EXP_RECE_SEARCH_ROUTES`） |
| 4 | `timestamp` | long | 是 | 调用接口时间戳 |
| 5 | `msgDigest` | String(128) | 条件 | 数字签名（与accessToken二选一） |
| 6 | `accessToken` | String | 条件 | 访问令牌，OAuth2方式认证时必填（与msgDigest二选一） |
| 7 | `msgData` | String | 是 | 业务数据报文 |

---

### 2.3 请求参数 `<msgData>`

| # | 属性名 | 类型(约束) | 必填 | 默认值 | 描述 |
|---|--------|-----------|------|--------|------|
| 1 | `language` | String(10) | 否 | zh-CN | 响应报文语言：`zh-CN` 中文简体 / `zh-TW\|zh-HK\|zh-MO` 中文繁体 / `en` 英文 |
| 2 | `trackingType` | Number(2) | **是** | 1 | 查询号类别：`1` 按顺丰运单号 / `2` 按客户订单号 |
| 3 | `trackingNumber` | List\<String\> | **是** | - | 查询号（类型由trackingType决定） |
| 4 | `methodType` | Number(1) | 否 | 1 | 路由查询类别：`1` 标准路由查询 / `2` 定制路由查询 |
| 5 | `referenceNumber` | String(4000) | 否 | - | 参考编码（目前针对亚马逊客户） |
| 6 | `checkPhoneNo` | String(30) | 否 | - | 电话号码验证（后4位，多个用英文逗号分隔） |

---

### 2.4 公共响应参数

| # | 属性名 | 类型(约束) | 必填 | 默认值 | 描述 |
|---|--------|-----------|------|--------|------|
| 1 | `success` | String | 是 | - | `true` 请求成功 / `false` 请求失败 |
| 2 | `errorCode` | String | 是 | - | 错误编码（`S0000` 成功） |
| 3 | `errorMsg` | String | 是 | - | 错误描述 |
| 4 | `msgData` | String | 是 | - | 返回的详细数据 |

---

### 2.5 响应参数 `<msgData>`

#### 2.5.1 routeResps（列表）

| 序号 | 参数列表 | 类型 | 是否必传 | 含义 |
|------|----------|------|----------|------|
| 1 | `mailNo` | String | 是 | 顺丰运单号 |
| 2 | `routes` | List | 是 | 路由信息列表 |

#### 2.5.2 routes（列表元素）

| 序号 | 参数列表 | 类型 | 是否必传 | 含义 |
|------|----------|------|----------|------|
| 1 | `acceptTime` | Date | 是 | 路由节点发生时间，格式 `YYYY-MM-DD HH24:MM:SS` |
| 2 | `acceptAddress` | String(100) | 否 | 路由节点发生的地点 |
| 3 | `remark` | String(150) | 是 | 路由节点具体描述 |
| 4 | `opCode` | String(20) | 是 | 路由节点操作码 |
| 5 | `firstStatusCode` | String(20) | 否 | 一级状态编码 |
| 6 | `firstStatusName` | String(20) | 否 | 一级状态名称 |
| 7 | `secondaryStatusCode` | String(20) | 是 | 二级状态编码 |
| 8 | `secondaryStatusName` | String(20) | 是 | 二级状态名称 |

> **注意事项**：
> - 同一批次顺丰运单路由信息必须为同一语言
> - 目前支持中文简体、中文繁体和英文
> - 定制路由查询须与顺丰商务人员沟通

### 2.6 请求示例 (JSON)

**请求报文1 - 按运单号查询**：

```json
{
    "language": "zh-CN",
    "trackingType": "1",
    "trackingNumber": ["444003077898", "441003077850"],
    "methodType": "1"
}
```

```json
{
    "trackingType": "1",
    "trackingNumber": ["SF3172850154171", "SF1110801143001"],
    "checkPhoneNo": "0001,0002"
}
```

## 3. 错误代码

### 3.1 平台结果码（API层）

| 标识 | 说明 | 解决方法 |
|------|------|----------|
| **A1000** | 统一接入平台校验成功，调用后端服务成功 | 表示接口调用正常（不代表业务处理成功，需查看apiResultData） |
| **A1001** | 必传参数不可为空 | 检查必填字段、Content-type、参数key空格、URL编码、msgData JSON格式、form表单 |
| **A1011** | OAuth2认证失败 | accessToken超过2小时，请重新获取 |
| **A1003** | IP无效 | partnerID配置了IP校验，请解除或按绑定IP调用 |
| **A1004** | 无对应服务权限 | 检查partnerID是否关联接口、环境是否一致、后台配置是否生效 |
| **A1005** | 流量受控 | 单接口限流：30次/s、3000次/天，请勿压测 |
| **A1006** | 数字签名无效 | 检查checkword、verifyCode/msgDigest加签、特殊字符 |
| **A1007** | 重复请求 | orderId请不要重复使用 |
| **A1008** | 数据解密失败 | 报障人工处理 |
| **A1009** | 目标服务异常或不可达 | 报障人工处理 |
| **A1010** | 状态为沙箱测试 | 报障人工处理 |
| **A1099** | 系统异常 | 报障人工处理 |

---

### 3.2 业务异常代码

| # | errorCode | 描述 | 处理建议 |
|---|-----------|------|----------|
| 9 | **6133** | 路由查询类别不合法 | methodType传 1 或 2 |
| 10 | **8013** | 未传入查询单号 | trackingNumber没有传值 |
| 11 | **8003** | 查询单号超过最大限制 | 一次最多查询10个单号 |
| 12 | **8004** | 路由查询条数超限制 | 一次最多查询10个单号 |

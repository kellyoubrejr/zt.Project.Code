# 图片注册及推送接口

> **接口服务代码**: `EXP_RECE_REGISTER_WAYBILL_PICTURE`

---

## 1. 功能描述

该接口支持客户根据运单号和图片类型进行注册，系统根据注册信息查询是否已经产生对应类型图片，如存在对应图片即生成对应推送任务，根据配置的推送地址推送对应图片信息。如对应图片推送失败，该接口会根据注册信息和推送任务进行重试。

> 由于图片产生的时间不固定，建议在运单妥投（签收）后再来注册获取相应图片。

---

## 2. 接口定义

### 2.1 公共参数

| 名称 | 值 |
|------|-----|
| 接口服务代码 | `EXP_RECE_REGISTER_WAYBILL_PICTURE` |
| 生产环境地址 | `https://bspgw.sf-express.com/std/service` |
| 香港生产环境 | `https://sfapi-hk.sf-express.com/std/service` |
| 沙箱环境地址 | `https://sfapi-sbox.sf-express.com/std/service` |
| 批量交易 | 不支持 |
| 接口类型 | 接入 |
| 报文类型 | JSON |

**关注点（详见开发规范）**

1. 通讯双方采用 HTTP 作为通讯协议；
2. 提交方式为 POST，请求头须添加 `Content-type: application/x-www-form-urlencoded`，字符集统一使用 UTF-8；
3. 参数需要通过 HTTP URL 编码传送；
4. 业务数据统一以字符串格式放在 `msgData` 字段中传送。

| A1001 | 必传参数不可为空 | 检查必填字段、Content-type、URL 编码、报文格式等 |

| A1005 | 流量受控 | 单接口 30 次/s、3000 次/天 |
| A1006 | 数字签名无效 | 检查 checkword、加签、特殊字符、form 表单格式 |
| A1007 | 重复请求 | 下单接口的 orderId 不要重复使用 |
| A1008 | 数据解密失败 | 报障人工处理 |
| A1009 | 目标服务异常或不可达 | 报障人工处理 |
| A1010 | 状态为沙箱测试 | 报障人工处理 |

### 3.2 业务异常代码

| # | errorCode | 描述 | 处理建议 |
|---|-----------|------|----------|
| 1 | 8201 | 月结卡号不匹配运单信息，图片注册失败 | 传入月结卡号与下单月结卡号不一致，跟销售经理确认卡号 |

## 4. 图片推送功能说明

### 4.1 说明

该功能用于推送顺丰签单、回单图片信息。推送方式为增量推送，当对接图片推送接口时，会接收到图片注册对应的图片信息。

需要在 `丰桥服务 >> 控制台 >> 开发者对接 >> 查看API >> 操作 >> 查看` 页面中找到添加好的图片注册及推送接口，获取解密密钥，用于图片的解密。

客户处理完 JSON 信息后，需向顺丰系统返回 JSON 报文，否则无法继续增量推送图片信息。

### 4.2 通讯协议与报文格式

- 通讯双方采用 HTTP POST 作为通讯协议。
- 请求头必须添加 `Content-type: application/json;charset=UTF-8`，字符集统一使用 UTF-8。

### 4.3 图片解密示例

> 图片 `content` 字段为 AES/CBC/PKCS5Padding 加密 + Base64 编码（两次 Base64）。解密密钥从控制台获取，下面示例密钥 `SECRET` 为 `axjGikUwgYVKiJ3A`。

```java
import com.alibaba.fastjson.JSON;
import com.alibaba.fastjson.JSONObject;
import org.apache.commons.codec.binary.Base64;
import javax.crypto.Cipher;
import javax.crypto.spec.IvParameterSpec;
import javax.crypto.spec.SecretKeySpec;
import java.nio.file.Files;
import java.nio.file.Paths;
import java.security.spec.AlgorithmParameterSpec;

public class Main {
    public static byte[] ivBytes = { 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00,
            0x00, 0x00, 0x00 };

    // 解密密钥（从控制台获取）
    private final static String SECRET = "axjGikUwgYVKiJ3A";

    public static void main(String[] args) throws Exception {
        String responseMsg = "{\"companyLogo\":\"SF\",\"content\":\"<base64密文>\",\"waybillNo\":\"SF1011854328486\"}";
        transferToImage(responseMsg);
    }

    public static void transferToImage(String msg) throws Exception {
        JSONObject s = JSON.parseObject(msg);
        byte[] decode = Base64.decodeBase64(s.getString("content"));
        decode = AES_Decode(decode, SECRET);
        decode = Base64.decodeBase64(new String(decode, "utf-8"));
        Files.write(Paths.get("D:/SF.png"), decode);
    }

    // 解密
    public static byte[] AES_Decode(byte[] textBytes, String key) throws Exception {
        AlgorithmParameterSpec ivSpec = new IvParameterSpec(ivBytes);
        SecretKeySpec newKey = new SecretKeySpec(key.getBytes("UTF-8"), "AES");
        Cipher cipherDncrypt = Cipher.getInstance("AES/CBC/PKCS5Padding");
        cipherDncrypt.init(Cipher.DECRYPT_MODE, newKey, ivSpec);
        return cipherDncrypt.doFinal(textBytes);
    }
}
```

### 4.4 请求参数（SF → CP）

| # | 元素名 | 类型（约束） | 是否必填 | 描述 |
|---|--------|-----------|---------|------|
| 1 | `content` | String | Y | 图片信息（内容加密） |
| 2 | `waybillNo` | String | Y | 运单号 |
| 3 | `companyLogo` | String | Y | 企业标识，默认 SF |

### 4.5 响应参数（CP → SF）

| 2 | `return_msg` | String | Y | 成功或失败说明 |

# 企业微信文件消息发送接口

## 接口概述

本接口用于通过企业微信应用发送文件消息给指定用户。基于企业微信消息发送API封装，提供简单的HTTP接口。

## 接口地址

```
POST /Interface/ToOther/WeComFileHandler.ashx
```

## 请求方式

POST，Content-Type: application/json

## 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| toUserChinese | string | 是 | 收件人中文姓名，多个用户用"\|"分隔（如："张三\|李四"） |
| media_id | string | 否* | 文件媒体ID，需要通过企业微信上传临时素材接口获取。与base64二选一 |
| base64 | string | 否* | 文件的Base64编码字符串，支持Data URI格式（如"data:application/pdf;base64,..."）。与media_id二选一 |
| fileName | string | 否 | 带扩展名的文件名（如"合同.pdf"），仅在传base64时有效。不传则自动生成.bin文件 |

> *media_id 和 base64 二选一必填。传base64时接口会自动上传素材并获取media_id。

## 请求示例

### 方式一：传media_id

```json
{
    "media_id": "1Yv-zXfHjSjU-7LH-GwtYqDGS-zz6w22KmWAT5COgP7o",
    "toUserChinese": "张三"
}
```

### 方式二：传base64（推荐，接口自动上传）

```json
{
    "toUserChinese": "张三",
    "base64": "data:application/pdf;base64,JVBERi0xLjQKJeLjz9MK...",
    "fileName": "合同.pdf"
}
```

## 响应参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| return_code | string | 返回码，0000表示成功 |
| return_msg | string | 返回信息 |
| data | object | 详细数据，成功时返回 |

### data对象参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| ToUser | string | 收件人中文姓名 |
| WeComUser | string | 企业微信用户名 |
| MediaId | string | 文件媒体ID |
| SendTime | string | 发送时间 |

## 响应示例

### 成功响应

```json
{
    "return_code": "0000",
    "return_msg": "文件消息发送成功",
    "data": {
        "ToUser": "张三",
        "WeComUser": "ZhangSan",
        "MediaId": "1Yv-zXfHjSjU-7LH-GwtYqDGS-zz6w22KmWAT5COgP7o",
        "SendTime": "2026-09-12 10:30:00"
    }
}
```

### 失败响应

```json
{
    "return_code": "1001",
    "return_msg": "文件媒体ID不能为空",
    "data": null
}
```

## 错误代码

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| 0000 | 成功 | - |
| 1000 | 请求报文为空 | 检查请求体是否为空 |
| 1001 | 文件媒体ID或base64数据不能为空 | 检查media_id或base64参数 |
| 1002 | 收件人不能为空 | 检查toUserChinese参数 |
| 2000 | K3Cloud登录失败 | 检查金蝶登录配置 |
| 2001 | 登录异常 | 检查网络或日志 |
| 3000 | 未找到收件人的企微用户映射 | 检查用户中文姓名是否在映射表中 |
| 4000 | 文件素材上传失败 | 检查base64数据是否正确，查看return_msg中的详细错误信息 |
| 9999 | 处理异常 | 查看错误日志 |

## 使用说明

1. **获取media_id**: 需要先通过企业微信上传临时素材接口获取文件的media_id
2. **用户映射**: 收件人必须是WeComUserMapping中定义的中文姓名
3. **多用户发送**: 支持多个用户，用"|"分隔，如："张三|李四|王五"
4. **异常处理**: 接口会记录日志但不抛出异常，通过return_code判断结果

## 示例代码（C#）

```csharp
// 发送文件消息示例
var client = new HttpClient();
var requestBody = new
{
    media_id = "your_media_id_here",
    toUserChinese = "张三"
};

string json = JsonConvert.SerializeObject(requestBody);
var content = new StringContent(json, Encoding.UTF8, "application/json");

var response = await client.PostAsync("http://your-server/Interface/ToOther/WeComFileHandler.ashx", content);
string result = await response.Content.ReadAsStringAsync();
```

## 支持的文件格式

企业微信支持以下格式的文件消息：
- 文本文件：txt、pdf、doc、docx、ppt、pptx、xls、xlsx、xml
- 图片文件：jpg、jpeg、png、bmp、gif

## 注意事项

1. **文件大小限制**：企业微信要求文件大小不超过20MB
2. **media_id有效期**：临时素材的media_id有效期为3天
3. **发送频率限制**：注意企业微信的API调用频率限制
4. **保密消息**：发送保密消息时，支持以下格式文件：txt、pdf、doc、docx、ppt、pptx、xls、xlsx、xml、jpg、jpeg、png、bmp、gif

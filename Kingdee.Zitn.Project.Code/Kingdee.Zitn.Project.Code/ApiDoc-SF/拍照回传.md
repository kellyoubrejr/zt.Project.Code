## **📸拍照回传传值示例：IN91为增值服务**

🔍**获取图片需调用 [图片注册与推送接口](https://open.sf-express.com/Api/ApiDetails?level3=403&interName=%E5%9B%BE%E7%89%87%E6%B3%A8%E5%86%8C%E5%8F%8A%E6%8E%A8%E9%80%81%E6%8E%A5%E5%8F%A3-EXP_RECE_REGISTER_WAYBILL_PICTURE "签收后调用该接口") 由于图片产生的时间不固定，建议在运单妥投（签收）后再来注册获取相应图片。**

**value** 为图片类型，固定传值13：签回单拍照
**value1** 为照片张数
**value2** 签回单内容可多个，英文逗号分隔， 1=签名，2=盖章，3=签名+盖章，4=身份证号码，5=签名+身份证号码，6=盖章+身份证号码，7=签名+盖章+身份证号码，8=【签收日期】9=【电话号码】
**value5** 备注，value5:”{\”remark\”:\”备注信息\”}”

#### 第二程关联第一程回单

**关注点：**①第二程单 需要将第一程返回的签回单号作为母单号（对应字段waybillNo，waybillType=1），原单母单号通过扩展字段传入（key:singBackOriNo ）②第二程订单产品需要限定为标快、特快，第二程下单时isSignBack不要传值，isGenWaybillNo传0。③第二程订单下单时系统会校验singBackOriNo 是否正确，系统可能存在时间差，建议第二程订单在一程订单下单成功后间隔一定时间（5秒以上）再下发第二程订单。或者客户系统做重试机制。

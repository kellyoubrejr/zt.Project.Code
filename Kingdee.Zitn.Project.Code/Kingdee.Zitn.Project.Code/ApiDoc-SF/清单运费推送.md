# 清单运费推送接口

> **接口服务代码**: `EXP_RECE_WAYBILLS_FEE_PUSH`

---

## 1. 功能描述

清单费用收费信息推送给客户，推送相关字段信息：订单号、运单号、子单号、月结账号等，根据配置的属性推送。

---

## 2. 接口定义

### 2.1 公共参数

| 名称 | 值 |
|------|-----|
| 接口服务代码 | `EXP_RECE_WAYBILLS_FEE_PUSH` |
| 批量交易 | 不支持 |
| 接口类型 | 推送 |
| 报文类型 | application/x-www-form-urlencoded |

---

## 3. 请求参数

| # | 元素名 | 类型（约束） | 必填 | 描述 |
|---|--------|-----------|------|------|
| 1 | `orderNo` | String | Y | 客户下单时传入的订单号 |
| 2 | `waybillNo` | String(100) | Y | 顺丰下单接口返回的 15 或 12 位运单号（母单号），如 `SF10116351372291` |
| 3 | `childNos` | String(100) | N | 子件运单号，多个逗号隔开 |
| 4 | `customerAcctCode` | String(100) | N | 10 位数字，用于账单结算的账号 |
| 5 | `meterageWeightQty` | String(100) | Y | 包裹计费重量（kg） |
| 6 | `realWeightQty` | String(100) | N | 实际重量（kg） |
| 7 | `productName` | String(100) | Y | 如顺丰特惠、顺丰标快 |
| 8 | `quantity` | String(100) | Y | 托寄物包裹数量 |
| 9 | `volume` | String(100) | N | 托寄物总体积 |
| 10 | `feeList` | List | N | 费用信息 |

## 7. 错误代码

### 7.1 平台结果码（API 层）

| 标识 | 说明 | 解决方法 |
|------|------|----------|
| A1000 | 统一接入平台校验成功 | 不代表业务成功，需看 apiResultData |
| A1001 | 必传参数不可为空 | 检查必填字段、Content-type、URL 编码等 |
| A1011 | OAuth2 认证失败 | accessToken 超过 2 小时需重新获取 |
| A1003 | IP 无效 | 解除 IP 校验或按绑定 IP 调用 |
| A1004 | 无对应服务权限 | 检查 partnerID 关联、环境一致性 |
| A1005 | 流量受控 | 单接口 30 次/s、3000 次/天 |
| A1006 | 数字签名无效 | 检查 checkword、加签、特殊字符 |
| A1007 | 重复请求 | orderId 不要重复使用 |
| A1008 | 数据解密失败 | 报障人工处理 |
| A1009 | 目标服务异常或不可达 | 报障人工处理 |
| A1010 | 状态为沙箱测试 | 报障人工处理 |
| A1099 | 系统异常 | 报障人工处理 |

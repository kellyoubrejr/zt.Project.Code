# 速运API · 路由推送接口

> **接口服务代码**: `RoutePushService`
>
> 接口类型：**推送**（顺丰主动推送给客户）

---

## 1. 功能描述

当路由信息生产后向客户主动推送要求的顺丰运单路由信息。推送方式为**增量推送**，对于同一个顺丰运单的同一个路由节点，不重复推送。仅推送通过丰桥接口下单的订单路由信息。

不管下订单是在测试环境还是生产环境，当选择了路由推送接口并填写了接收地址，下单会自动生成测试路由并推送。客户接口能正常接收并正确响应，则测试成功。

### 接收规范

客户需提供一个符合以下规范的 HTTP 或 HTTPS URL：

| 请求方法 | Content-Type | 数据格式 |
|----------|-------------|----------|
| **json** | `application/json;charset=UTF-8` | JSON |
| **form** | `application/x-www-form-urlencoded;charset=UTF-8` | 请求参数为 `content`，URL编码(UTF-8)的XML |

请求方式为 **HTTP POST**。

### 响应要求

| 请求方法 | 响应格式 | 成功 | 失败 |
|----------|----------|------|------|
| form (XML) | XML | `<Head>OK</Head>` | `<Head>ERR</Head>` + 错误码 |
| json | JSON | `{"return_code":"0000","return_msg":"成功"}` | `{"return_code":"1000","return_msg":"..."}` |

> **沙箱环境推送频率**：10min/次，沙箱测试环境每单固定推送两条路由数据

## 2. 接口定义

### 2.1 公共参数

| 名称 | 值 |
|------|-----|
| 接口服务代码 | `RoutePushService` |
| 批量交易 | 最多10个WaybillRoute元素 |
| 接口类型 | 推送 |
| 报文类型 | `application/x-www-form-urlencoded` |

---

### 2.2 请求参数 `/WaybillRoute`

| # | 属性名 | 类型（约束） | 必填 | 默认值 | 描述 |
|---|--------|-------------|------|--------|------|
| 1 | `mailno` | String | - | - | 客户运单号 |
| 2 | `acceptAddress` | String | - | - | 收货地址 |
| 3 | `reasonName` | String | - | - | 异常描述 |
| 4 | `orderid` | String | - | - | 客户订单号 |
| 5 | `acceptTime` | String | - | - | 收货时间 |
| 6 | `remark` | String | - | - | 备注 |
| 7 | `opCode` | String | - | - | 操作码 |
| 8 | `id` | String | - | - | ID |
| 9 | `reasonCode` | String | - | - | 异常编码 |
| 10 | `firstStatusCode` | String | - | - | 一级状态码 |
| 11 | `firstStatusName` | String | - | - | 一级状态码描述 |
| 12 | `secondaryStatusCode` | String | - | - | 二级状态码 |
| 13 | `secondaryStatusName` | String | - | - | 二级状态码描述 |

> **注意事项**：
> 1. 需要与顺丰商务人员沟通确认路由信息的语言（中文简体/繁体/英文）
> 2. 标准路由推送 vs 定制路由推送需提前确认
> 3. 查看路由信息操作码

---

### 2.3 响应参数

| # | 元素名 | 类型（约束） | 必填 | 描述 |
|---|--------|-------------|------|------|
| 1 | `return_code` | String | Y | 返回响应码（`0000` 成功 / `1000` 失败） |
| 2 | `return_msg` | String | Y | 返回消息 |

## 3. 错误代码

### 3.1 平台结果码（API层）

| 标识 | 说明 | 解决方法 |
|------|------|----------|
| **A1000** | 统一接入平台校验成功 | 表示接口调用正常（不代表业务处理成功） |
| **A1001** | 必传参数不可为空 | 检查必填字段、Content-type、参数key空格、URL编码等 |
| **A1011** | OAuth2认证失败 | accessToken超过2小时，请重新获取 |
| **A1003** | IP无效 | 解除IP校验或按绑定IP调用 |
| **A1004** | 无对应服务权限 | 检查partnerID关联、环境一致性 |
| **A1005** | 流量受控 | 单接口30次/s、3000次/天 |
| **A1006** | 数字签名无效 | 检查checkword、加签、特殊字符 |
| **A1007** | 重复请求 | orderId不要重复使用 |
| **A1008** | 数据解密失败 | 报障人工处理 |
| **A1009** | 目标服务异常或不可达 | 报障人工处理 |
| **A1010** | 状态为沙箱测试 | 报障人工处理 |
| **A1099** | 系统异常 | 报障人工处理 |

---

| errorCode | 描述 | 分类 |
|-----------|------|------|

| **S0002** | 必填参数为空 | 系统错误 |
| **S0003** | 系统发生数据错误或运行时异常 | 系统错误 |

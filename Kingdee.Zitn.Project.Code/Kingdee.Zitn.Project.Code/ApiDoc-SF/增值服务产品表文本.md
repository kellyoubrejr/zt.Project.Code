
### 拍照回传 (IN91)

| 项目               | 说明                                                                                                                                                                                                                                                                                                                                                                        |
| :----------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **服务代码** | IN91                                                                                                                                                                                                                                                                                                                                                                        |
| **说明**     | value为图片类型，**13** 代表签回单拍照（固定传值）。value1：照片张数。value2：签回单内容（可多选，用英文逗号分隔），选项包括：1-签名, 2-盖章, 3-签名+盖章, 4-身份证号码, 5-签名+身份证号码, 6-盖章+身份证号码, 7-签名+盖章+身份证号码, 8-签收日期, 9-电话号码, 10-姓名, 11-姓名+身份证号码, 12-姓名+身份证号码……（编号持续至354，内容重复或延续）value5：备注信息。 |
| **入参示例** | `"serviceList":[{"name":"IN91","value":"13","value1":"1","value2":"1","value5":"{\"remark\":\"客户签名，上传白联，拍照清晰正向上传，单据信息完整无遮挡。照片请签收后24小时内上传\"}"}]`                                                                                                                                                                                   |

> **请注意**：图片中 `value2` 的选项列表从 `1` 编号至 `354`，但后半部分内容（从编号12开始）在提供的文本中显示为大量重复的“姓名+身份证号码”，这可能为图片截取或识别错误。实际有效选项请以官方最新文档为准，通常为前9-11项。


## 签单返还（纸质回单）(IN03)

| 项目               | 说明                                                                                                   |
| :----------------- | :----------------------------------------------------------------------------------------------------- |
| **服务代码** | IN03                                                                                                   |
| **重要说明** | **下订单时不需要在 serviceList 中传入 IN03**，此处仅用于费用代码说明。实际通过订单扩展字段控制。 |

### 控制字段说明

| 字段                     | 是否必传               | 说明                                                                                                                                                                                          |
| :----------------------- | :--------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **isSignBack**     | 是                     | 是否要求签回单：1-要求，0-不要求                                                                                                                                                              |
| **attr014**        | 是（当isSignBack=1时） | 签回单标识，固定传值`"singBackInfo"`                                                                                                                                                        |
| **attr015**        | 是（当isSignBack=1时） | 签回单具体内容（与attr014配合使用，多个值用英文逗号分隔）：1-签名，2-盖章，3-登记身份证号，4-收取身份证复印件，5-【收取派件存根】(香港专用)，6-【其他文件】(香港专用)，7-签收日期，8-电话号码 |
| **signbackNum**    | 否                     | 签回单份数                                                                                                                                                                                    |
| **signBackRemark** | 否                     | 签回单备注信息                                                                                                                                                                                |

### 使用示例

**下单时无需在 serviceList 中传入 IN03**，而是在订单其他参数中设置：

```json
{
  "isSignBack": "1",
  "attr014": "singBackInfo",
  "attr015": "1,2,7",
  "signbackNum": "2",
  "signBackRemark": "请客户签名并盖章"
}
```

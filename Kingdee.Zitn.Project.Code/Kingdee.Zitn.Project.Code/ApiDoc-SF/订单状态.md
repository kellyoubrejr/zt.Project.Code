# 速运API · 订单状态推送接口

> **接口服务代码**: `PushOrderState`
>
> 接口类型：**推送**（顺丰主动推送给客户）
>
> 仅限于推送预约上门订单调度状态，非预约订单不推送。

---

## 1. 功能描述

此接口用于订单状态推送，将订单状态的各类信息推送给对接的客户。

---

## 2. 接口定义

### 2.1 公共参数

| 名称 | 值 |
|------|-----|
| 接口服务代码 | `PushOrderState` |
| 接口方式 | HTTP POST `Content-type: application/xml;charset=UTF-8` |
| 接口类型 | 推送 |
| 报文类型 | 支持3种格式：`form` / `xml` / `json`（客户自行选择） |

---

### 2.2 请求参数 `<msgData>`

| # | 属性名 | 类型(约束) | 必填 | 描述 |
|---|--------|-----------|------|------|
| 1 | `orderNo` | String(64) | **是** | 客户订单号 |
| 2 | `waybillNo` | String(64) | 否 | 顺丰运单号 |
| 3 | `orderStateCode` | String(20) | **是** | 订单状态（见下方状态编码表） |
| 4 | `orderStateDesc` | String(200) | **是** | 订单状态描述 |
| 5 | `empCode` | String(100) | 否 | 收件员工工号 |
| 6 | `empPhone` | String(100) | 否 | 收件员手机号 |
| 7 | `netCode` | String(20) | 否 | 网点 |
| 8 | `lastTime` | date | 否 | 最晚上门时间 |
| 9 | `bookTime` | date | 否 | 客户预约时间 |
| 10 | `carrierCode` | String(10) | **是** | 承运商代码（`SF`） |

---

### 2.3 响应参数 `<apiResultData>`

| # | 属性名 | 类型(约束) | 必填 | 默认值 | 描述 |
|---|--------|-----------|------|--------|------|
| 1 | `success` | String(10) | 是 | - | 是否成功接收：`true` 是 / `false` 否 |
| 2 | `msg` | String(200) | 否 | - | 接收失败异常描述 |

---

### 2.4 请求示例 (JSON)

```json
{
    "requestId": "0597a8d2-42e3-46d6-86e9-14acf03598de",
    "timestamp": "1630376445286",
    "orderState": [{
        "orderNo": "442321000025419019",
        "waybillNo": "SF7444778095881",
        "orderStateCode": "04",
        "orderStateDesc": "调度失败/等待",
        "empCode": "",
        "empPhone": "",
        "netCode": "755A",
        "lastTime": "2021-08-31 09:00:00",
        "bookTime": "2021-08-31 09:00:00",
        "carrierCode": "SF",
        "createTm": "2021-08-31 09:00:00"
    }]
}
```

---

### 2.5 返回示例 (JSON)

**成功响应**：

```json
{
    "success": "true",
    "code": "0",
    "msg": ""
}
```

**失败响应**：

```json
{
    "success": "false",
    "msg": "订单状态接收异常"
}
```

---

---

**成功响应**：

```xml
<?xml version="1.0" encoding="UTF-8" ?>

    <success>true</success>
</Response>
```

**失败响应**：

```xml
<?xml version="1.0" encoding="UTF-8" ?>

    <success>false</success>
    <msg>订单状态接收异常</msg>
</Response>
```

## 3. 错误代码

### 3.1 平台结果码（API层）

| 标识 | 说明 | 解决方法 |
|------|------|----------|
| **A1000** | 统一接入平台校验成功，调用后端服务成功 | 表示接口调用正常（不代表业务处理成功） |
| **A1001** | 必传参数不可为空 | 检查必填字段、Content-type、参数key空格、URL编码等 |
| **A1011** | OAuth2认证失败 | accessToken超过2小时，请重新获取 |
| **A1003** | IP无效 | 解除IP校验或按绑定IP调用 |
| **A1004** | 无对应服务权限 | 检查partnerID关联、环境一致性 |
| **A1005** | 流量受控 | 单接口30次/s、3000次/天 |
| **A1006** | 数字签名无效 | 检查checkword、加签、特殊字符 |
| **A1007** | 重复请求 | orderId不要重复使用 |
| **A1008** | 数据解密失败 | 报障人工处理 |
| **A1009** | 目标服务异常或不可达 | 报障人工处理 |
| **A1010** | 状态为沙箱测试 | 报障人工处理 |
| **A1099** | 系统异常 | 报障人工处理 |

---

### 3.2 业务异常代码

| errorCode | 描述 | 分类 |
|-----------|------|------|
| **S0000** | 成功 | 成功 |
